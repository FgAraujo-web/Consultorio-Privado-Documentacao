# Consultório Privado — Documentação Técnica e Funcional

## Apresentação

O **Consultório Privado** é uma prova de conceito (POC) de desenvolvimento de Sistemas de Informação, implementada em **ASP.NET Core MVC (.NET 10)**, com **C#, Entity Framework Core e Microsoft SQL Server**.

O projeto demonstra a conceção e implementação de uma aplicação web de gestão de consultório médico, desde a modelação da base de dados e arquitetura aplicacional até à implementação das regras de negócio e interfaces de utilização.

## Funcionalidades

- Gestão de utentes, médicos e especialidades.
- Gestão de horários e indisponibilidades médicas.
- Agendamento de consultas, com validação de disponibilidade e prevenção de sobreposições.
- Agenda semanal de consultas.
- Gestão de atos clínicos e pagamentos.
- Dashboard de acompanhamento operacional.
